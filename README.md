# Seema Singdan – Portfolio

My personal portfolio website, built with React, Vite and Tailwind CSS.

## Run it locally

You need Node.js 20.19 or newer.

```cmd
npm install
npm run dev
```

Then open http://localhost:5173.

## Update the content

All text (intro, projects, skills, education, certificates and contact links) is in
`src/data/profile.js`. Edit that file and the site updates.

## Build for hosting

```cmd
npm run build
```

The finished site is in the `dist` folder. It can be hosted for free on Vercel or Netlify.
